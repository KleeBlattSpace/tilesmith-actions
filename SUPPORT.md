# Support

Thanks for using TileSmith QC! Here is the fastest way to get help:

| Situation                                         | Where to go                                                                                                           |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 🐛 Bug or unexpected behavior in this action      | [Open a GitHub issue](https://github.com/KleeBlattSpace/tilesmith-actions/issues/new?template=bug_report.yml)         |
| 💡 Feature idea or improvement                    | [Open a feature request](https://github.com/KleeBlattSpace/tilesmith-actions/issues/new?template=feature_request.yml) |
| ❓ Questions, usage help, show & tell             | [GitHub Discussions](https://github.com/KleeBlattSpace/tilesmith-actions/discussions)                                 |
| 🔑 API key, quota, or billing (TileSmith account) | [TileSmith dashboard](https://app.kleeblatt.space) or email [support@kleeblatt.space](mailto:support@kleeblatt.space) |
| 🔒 Security vulnerability                         | Follow [SECURITY.md](SECURITY.md) — do **not** open a public issue                                                    |

## Before you open an issue

1. Check the [FAQ in the README](README.md#faq-and-troubleshooting) — fork PRs, quota, exit codes, and `paths` matching are covered there.
2. Look through [existing issues](https://github.com/KleeBlattSpace/tilesmith-actions/issues?q=is%3Aissue) — your question may already be answered.
3. Include the information requested by the issue template (action version, workflow excerpt **without secrets**, run link). Never post your API key — we don't need it to help you.

## Response expectations

This is a free, community-supported action: we aim to respond to issues and discussions within a few business days. Security reports are handled with priority — see [SECURITY.md](SECURITY.md).
