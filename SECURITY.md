# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately and do not open a public issue containing credentials, API keys, or an exploitable proof of concept.

- **Preferred:** [GitHub Security Advisories](https://github.com/KleeBlattSpace/tilesmith-actions/security/advisories/new)
- **Alternative:** email [support@kleeblatt.space](mailto:support@kleeblatt.space) with the subject `Security: tilesmith-actions`

We will acknowledge valid reports and coordinate remediation and disclosure timelines with the reporter.
